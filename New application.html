✓ Key Points to Remember

●

Sequential approval: SBM → IT → DPO (each stage only begins after previous approval)

●

Rejection stops the process: DPO is notified and handles requester communication

●

Headteacher/SLT aware: Notified automatically at the start once form submitted

●

Automatic notifications: All relevant parties notified at each stage

●

Full visibility: All approvers can see current status on the Monday board

●

DPIA triggers: Large sensitive data, new CCTV, monitoring, or biometrics
